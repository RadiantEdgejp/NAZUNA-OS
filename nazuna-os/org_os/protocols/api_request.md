# api_request プロトコル

## 目的
API実行を許可制で統制し、コード変更・デプロイ以外の不要実行を防ぐ。

## やること
- API実行前に目的、対象、影響範囲、ロールバック手順を記載する。
- 承認者がコード変更/デプロイ目的かを確認する。
- 実行後に結果とログIDを記録する。

## 禁止
- 無承認のAPI実行。
- 目的外のAPI利用。
- 実行結果の未記録。

## 入出力
- 入力: API実行申請、差分、デプロイ計画。
- 出力: 承認/却下結果、実行ログ、監査証跡。

## 成功条件
- すべてのAPI実行に承認記録がある。
- 監査時に申請〜実行まで追跡できる。
